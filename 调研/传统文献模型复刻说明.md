# 传统文献模型复刻说明

本次复刻只运行传统机器学习模型，不使用神经网络、不提取 CNN embedding，也不参与当前核心建模的模型选择。为了避免提前暴露最终测试集，脚本默认只在 validation split 输出指标和逐图分类结果；test split 仍保持封存。

## 运行脚本

```bash
/Users/wanzhaoning/.local/bin/python3.12 scripts/04_modeling/06_literature_traditional_model_reproduction.py --pilot-samples 800 --pilot-eval-samples 300
```

脚本会在每个候选模型训练前先做小样本 pilot timing，并打印估算训练时间；每完成一个候选就写一次 checkpoint。

## 输出文件

| 文件 | 内容 |
|---|---|
| `data/processed/model_reports/literature_traditional_results.csv` | 每个文献候选的 validation 汇总指标、估算耗时、实际耗时、参数说明 |
| `data/processed/model_reports/literature_traditional_per_class.csv` | 每个候选的逐类 precision / recall / F1 |
| `data/processed/model_reports/literature_traditional_validation_predictions.csv` | 每个 validation 图像的预测类别与是否正确 |
| `data/processed/model_reports/literature_traditional_confusion_matrices.csv` | 长表格式混淆矩阵 |
| `data/processed/model_reports/literature_traditional_summary.json` | JSON 汇总、候选配置、输出清单 |
| `data/processed/model_reports/literature_traditional_validation_predictions.npz` | validation 预测数组 |

## 文献候选与本地映射

| 候选 ID | 来源 | 本地特征 | 本地模型与参数来源 |
|---|---|---|---|
| `yang_thung_2016_sift_bof_rbf_svm` | Yang & Thung (2016), *Classification of Trash for Recyclability Status* | `F6_sift_bof` | 论文明确给出 RBF SVM，`C=1000`，`gamma=0.5`；本项目使用已由 train split 拟合的 128-word SIFT BoF |
| `nguyen_2026_handcrafted_lightgbm` | Nguyen et al. (2026), *Towards Accurate and Efficient Waste Image Classification* | `F1_color + F2_texture + F4_shape + F5_gist + F6_bof` | 论文给出手工特征 + LightGBM 模型族，但未列完整超参；本地使用显式固定 LightGBM 参数 |
| `nguyen_2026_handcrafted_xgboost` | Nguyen et al. (2026) | `F1_color + F2_texture + F4_shape + F5_gist + F6_bof` | 论文给出手工特征 + XGBoost 模型族，但未列完整超参；本地使用显式固定 XGBoost 参数 |
| `mboli_ogungbemi_2026_rgb_pca_random_forest` | Mboli & Ogungbemi (2026), *AI-Enabled Waste Classification...* | `F0_pixels_rgb` | 论文比较 PCA + Random Forest 等传统模型；本地以 32x32 RGB 像素作为图像数组近似，PCA 固定为 100 维 |
| `mboli_ogungbemi_2026_rgb_pca_rbf_svm` | Mboli & Ogungbemi (2026) | `F0_pixels_rgb` | 论文比较 PCA + SVM；本地使用 StandardScaler + PCA(100) + RBF SVC 默认核心参数 |
| `sen_2025_hog_lbp_linear_svm_reference` | Sen et al. (2025), *Feature Engineering is Not Dead* | `F3_hog + F2_texture` | 该文献是传统图像分类参考而非垃圾专用研究；本地使用 HOG + 纹理特征和可扩展 hinge-loss 线性 SVM |

## 当前 validation 结果

| 候选 ID | Accuracy | Macro-F1 | 少数类 recall 均值 | 实际训练耗时 |
|---|---:|---:|---:|---:|
| `nguyen_2026_handcrafted_lightgbm` | 0.7656 | 0.7653 | 0.7932 | 76.0s |
