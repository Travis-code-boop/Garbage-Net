# 传统机器学习图像垃圾分类方法与分类器速查表

## 1. 图像特征、预处理与特征工程方法

| 名称 | 核心方法 | 能力 |
|---|---|---|
| 图像预处理 | 读取图像后统一尺寸、转换颜色空间、可选地提取主体区域，再进行特征提取和特征标准化。 | 减少尺寸、光照、背景、颜色空间差异对模型的干扰，使图像能够稳定转化为结构化特征。 |
| 统一尺寸 | 将所有图像缩放到固定大小，如 256x256 或 400x400。 | 保证每张图像产生相同长度的像素向量或手工特征，便于进入传统模型。 |
| 主体区域提取 | 使用阈值分割、边缘检测、最大轮廓、外接矩形、GrabCut 等方法从背景中提取垃圾主体。 | 减少桌面、墙面、阴影等背景信息影响，使颜色、纹理、形状特征更集中于垃圾物体。 |
| 分层划分 | 按类别比例划分训练集、验证集和测试集。 | 在类别不平衡时保持各数据子集的类别分布一致，使 accuracy、macro-F1 等评价更稳定。 |
| 原始像素特征 | 将固定尺寸图像按行列顺序展平成一维向量，可使用灰度图或 RGB 三通道。 | 保留最直接的图像强度信息，可作为 baseline；但维度高，容易受物体位置和姿态变化影响。 |
| 灰度图 | 将 RGB 图像转换为单通道亮度图。 | 降低维度，便于提取纹理、梯度、边缘、GLCM、LBP、HOG 等特征。 |
| RGB | 使用红、绿、蓝三个原始颜色通道表示图像。 | 保留相机采集的基础颜色信息，适合计算颜色直方图和通道统计量。 |
| BGR | 与 RGB 通道顺序不同，常见于 OpenCV 的默认图像表示。 | 适合与 OpenCV 工具链配合使用，可提取颜色直方图和颜色统计量。 |
| HSV | 将颜色拆为 Hue、Saturation、Value，即色相、饱和度、亮度。 | 比 RGB 更接近人对颜色的直观理解，适合描述材料颜色、颜色鲜艳程度和亮度变化。 |
| HSV 图/HSV 直方图 | 将像素映射到 H、S、V 通道，并统计各取值区间内像素频数。 | 描述整张图像的颜色分布，可帮助区分 biological、paper、cardboard、glass、plastic 等具有颜色差异的类别。 |
| RGB/BGR/HSV 颜色直方图 | 对每个颜色通道或多维颜色空间统计像素落入不同区间的频数。 | 不依赖具体像素位置，能概括图像整体颜色组成；适合作为轻量颜色特征。 |
| 颜色统计量 | 计算各颜色通道的均值、标准差、偏度、峰度、最大值、最小值、熵等。 | 用少量变量描述整体颜色倾向、颜色变化程度和颜色复杂度，特征维度低、解释性强。 |
| 分块颜色统计/分块颜色直方图 | 将图像划分为多个区域，在每个区域分别计算颜色直方图或统计量。 | 在颜色特征中加入粗略空间信息，缓解普通颜色直方图完全忽略位置的问题。 |
| GLCM | 灰度共生矩阵，统计给定距离和方向上两个像素灰度值共同出现的频率。 | 描述局部灰度共现关系，适合刻画纸张、纸板、布料、金属、塑料表面的纹理结构。 |
| Haralick 特征 | 基于 GLCM 计算 contrast、homogeneity、energy、correlation 等统计量。 | 将共生矩阵压缩为可解释的纹理指标，能描述粗糙度、平滑度、重复性和灰度相关性。 |
| LBP | 局部二值模式，将邻域像素与中心像素比较，大于等于中心值记为 1，否则记为 0，再统计编码直方图。 | 捕捉局部微纹理，对单调光照变化较鲁棒，适合区分纸板纤维、布料、鞋面、塑料表面等。 |
| HOG | 方向梯度直方图，计算局部梯度方向和幅值，在 cell 内统计方向直方图，并在 block 中归一化。 | 描述物体边缘和轮廓结构，可捕捉纸盒、电池、鞋子、瓶状物等形状边缘；常与 SVM 搭配。 |
| 形状特征 | 通过阈值分割、边缘检测或轮廓检测获得主体区域，再计算几何量。 | 描述垃圾主体外部轮廓和几何结构，适合作为颜色、纹理之外的补充信息。 |
| 轮廓特征 | 找到主要轮廓或最大轮廓，计算面积、周长、外接矩形、长宽比、圆形度、凸包面积等。 | 区分细长、规则、不规则、近圆形或盒状物体，但依赖主体分割质量。 |
| Hu moments | 基于图像矩计算的一组形状描述量，具有平移、尺度、旋转不变性。 | 用少量变量描述整体形状，适合加入传统分类器进行可解释建模。 |
| 几何统计 | 面积、周长、长宽比、extent、solidity、圆形度等形状变量。 | 低维、直观，可描述电池、纸盒、鞋子、瓶状物等物体的粗略几何差异。 |
| SIFT | 在尺度空间中寻找稳定关键点，并为每个关键点构造局部梯度方向描述子，常为 128 维。 | 对尺度、旋转和一定光照变化较鲁棒，适合捕捉商标、角点、褶皱、边缘等局部结构。 |
| ORB | 结合 FAST 关键点检测和 BRIEF 描述子的轻量局部特征。 | 速度快、计算成本较低，可作为 SIFT 的轻量替代，但描述能力通常弱于 SIFT。 |
| 视觉词袋/Bag of Features | 将大量局部描述子用 k-means 聚类成视觉词，再把每张图表示为视觉词频直方图。 | 将每张图数量不等的 SIFT/ORB 局部描述子转化为固定长度向量，便于输入 SVM、随机森林等模型。 |
| GIST | 使用多尺度、多方向 Gabor 滤波器提取图像整体响应，再按网格统计。 | 描述图像全局空间结构和整体布局，不依赖少数关键点，适合补充局部特征。 |
| 熵 | 统计灰度或颜色分布的不确定性。 | 衡量图像颜色或纹理复杂度；颜色集中时熵低，颜色/纹理变化丰富时熵高。 |
| 像素分布特征 | 统计灰度直方图、亮度分位数、颜色直方图、前景/背景像素比例等。 | 用轻量方式概括图像整体像素分布，可与 HOG、LBP、HSV 等特征融合。 |
| 特征融合 | 将颜色、纹理、梯度、形状、关键点、全局特征按列拼接为联合特征向量。 | 让模型同时利用图像多个侧面的信息，弥补单一特征表达能力不足的问题。 |
| StandardScaler | 对每个特征减去均值并除以标准差。 | 消除量纲和尺度差异，尤其适合 SVM、KNN、Logistic Regression、PCA。 |
| MinMaxScaler | 将特征缩放到固定范围，如 0 到 1。 | 保持原始分布形态的同时统一尺度，适合距离模型和需要归一化输入的流程。 |
| PCA | 将高维特征投影到少数主成分上，保留主要方差信息。 | 降低维度和计算成本，缓解高维图像特征带来的过拟合；但可能压缩掉有助于分类的细节。 |
| 低方差过滤 | 删除在样本中几乎不变化的特征。 | 去除对分类贡献较小的变量，降低维度和噪声。 |
| ANOVA 特征选择 | 对每个输入变量检验不同类别下均值差异是否显著。 | 筛选与类别差异关联较强的特征，适合数值特征和分类输出变量。 |
| RFE | 递归式特征剔除，反复训练模型并删除当前最不重要的特征。 | 通过模型表现或系数逐步筛选变量，形成包裹式特征选择流程。 |
| L1 正则化特征选择 | 在模型损失函数中加入 L1 惩罚，使部分系数被压缩为 0。 | 实现嵌入式特征选择，适合高维稀疏特征，可得到更简洁的模型。 |

## 2. 常用传统分类器与已有结论

| 名称 | 核心方法 | 能力 |
|---|---|---|
| Logistic Regression / Softmax Regression | Logistic Regression 用线性函数建模二分类 logit，Softmax Regression 将其扩展到多分类，通常配合交叉熵损失和 L1/L2 正则化。 | 适合作为线性基线，训练快、可解释；但对非线性分类边界刻画能力有限。 |
| KNN | 对新样本，在特征空间中寻找距离最近的 K 个训练样本，通过多数投票给出类别。 | 体现局部相似性思想，简单直观；但对特征尺度和维度非常敏感，高维图像特征中容易受维度灾难影响。 |
| SVM | 在特征空间中寻找最大间隔分类超平面，可通过 RBF、多项式等核函数处理非线性边界。 | 是传统图像分类中的强基线，适合中高维特征；需要标准化，并调节 C、gamma、kernel 等超参数。 |
| Decision Tree | 通过递归分裂输入空间，使节点内类别异质性下降，形成 if-then 规则。 | 可解释性强，可输出规则和特征重要性；但单棵树容易过拟合，需要预剪枝或后剪枝。 |
| Random Forest | 基于 Bootstrap 抽样训练多棵决策树，每棵树再随机抽取部分特征进行分裂，最终投票分类。 | 比单棵树更稳健，能降低高方差，适合融合后的手工特征，也可输出特征重要性。 |
| Boosting | 顺序训练多个弱学习器，使后续模型更关注前一轮预测错误或残差较大的样本。 | 能把多个弱模型组合成强模型，适合提升传统特征上的分类性能，但需要控制过拟合。 |
| XGBoost | 梯度提升树框架，利用一阶/二阶梯度构造目标函数，并加入正则化项控制模型复杂度。 | 在手工特征垃圾分类 benchmark 中常表现较强，能处理非线性关系和特征交互，泛化能力较好。 |
| LightGBM | 轻量级梯度提升树，使用直方图算法、叶子优先生长和梯度单边采样等策略提高效率。 | 在大样本和高维特征下训练效率高，常与 XGBoost 一起作为传统机器学习强模型。 |
