# 论文可用文献综述段落

图像垃圾分类是计算机视觉在智能回收和自动化垃圾分拣中的典型应用，其核心在于将非结构化图像转化为可供分类模型学习的结构化特征。在深度学习方法普及之前，相关研究主要依赖图像预处理、手工特征提取和传统机器学习分类器完成识别任务。Yang 和 Thung（2016）基于 TrashNet 数据集开展了较早的垃圾图像分类研究，将垃圾图像划分为 glass、paper、metal、plastic、cardboard 和 trash 六类，并采用 SIFT 局部关键点特征、Bag of Features 视觉词袋表示和 RBF 核支持向量机进行分类。该方法首先从图像中提取尺度和旋转相对鲁棒的局部描述子，再通过 k-means 聚类形成固定长度的视觉词频向量，最后利用支持向量机建立非线性分类边界。其实验结果表明，SIFT 与 SVM 的组合能够在垃圾图像分类任务中取得一定效果，但 trash 等样本量较少、类内差异较大的类别仍存在较低的识别性能，说明类别不平衡和类别内部视觉差异是传统机器学习垃圾分类中的重要困难。

后续研究进一步扩展了传统特征体系，不再只依赖单一局部特征，而是将颜色、纹理、形状、关键点和全局结构等多种手工特征融合建模。Nguyen 等（2025/2026）在多个垃圾图像数据集上比较了手工特征结合传统机器学习模型的表现，其特征工程包括 HSV/BGR 颜色直方图、颜色统计量、轮廓几何特征、Hu moments、GLCM、LBP、ORB、SIFT 和 GIST 等。其中，颜色特征用于描述不同垃圾材料的色彩分布，GLCM 和 LBP 用于刻画纸张、纸板、布料、金属或塑料表面的纹理差异，HOG、轮廓和 Hu moments 等形状特征则可反映物体边缘和几何结构。该类方法的一般流程是先对图像进行尺寸统一、主体区域提取和颜色空间转换，再提取多组手工特征并拼接为高维特征向量，随后通过特征选择或降维减少冗余，最后输入 Logistic Regression、KNN、SVM、Decision Tree、Random Forest、XGBoost 和 LightGBM 等传统分类器。相关结果显示，单一线性模型或单棵决策树的表现通常有限，而随机森林、XGBoost 和 LightGBM 等集成学习模型在手工特征条件下具有更好的分类效果和稳定性，这与集成学习通过降低方差或逐步修正误差提升泛化能力的机制相一致。

除多分类垃圾识别外，也有研究从二分类废弃物识别角度比较传统机器学习模型。Mboli 和 Ogungbemi（2026）以有机废弃物和可回收废弃物分类为任务，比较了 Random Forest、XGBoost、Naive Bayes、AdaBoost、SVM 和 Logistic Regression 等传统模型，并考察 PCA 降维对模型性能的影响。其结果表明，Random Forest 和 XGBoost 在传统模型中表现相对较好，而 PCA 并不总是带来稳定提升，某些情况下还可能压缩掉有助于分类的细节信息。这说明，在图像垃圾分类中，降维和特征选择需要结合具体模型和数据特征进行验证，而不能简单认为维度越低模型越优。总体来看，已有研究表明，传统机器学习方法在垃圾图像分类中具有可解释性强、训练成本低、模型结构清晰等优点，但其性能高度依赖特征工程质量；面对背景复杂、类间差异细微、类内变化较大和类别不平衡的数据时，需要结合颜色、纹理、形状、梯度和局部关键点等多源特征，并通过标准化、特征选择、模型调参和宏平均 F1、混淆矩阵等评价指标全面分析模型效果。
